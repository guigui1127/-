# 腳本結構庫

一語成林腳本結構庫收錄十一種可重複使用的腳本骨架，分成故事型與教學型兩大類。

用法很直接：先問自己「這支內容想達成什麼」，對照文末的「怎麼選」對照表選出對應結構，再照該結構的分段公式把內容填進去。動筆前可以先打開你的 `我的品牌根系.md`，把裡面的內容支柱、品牌故事、常用數字拿出來對照，下面每個結構的「範例骨架」裡的括號，都是留給你填自己的故事用的。

---

## 一、故事型結構（六種）

### 1. 英雄旅程

六幕式敘事弧，從困境走到解方，收在行動指令，是最完整的故事版型。

**適用情境：** 長版故事型 Reels、YouTube 開場、電子報開場鉤，需要完整鋪陳一段轉變的時候。

**逐段拆法：**
1. 開場鉤：「X 年前，我（困境）」
2. 掙扎：試過哪些方法都沒用
3. 轉折點：遇到關鍵事件或洞察
4. 行動：開始做不一樣的事
5. 結果：現在的樣子
6. 收尾：導向你的系統或服務的行動指令

**範例骨架：**
「（填入時間點）年前，我（填入當時的處境），試了（填入方法一）、（填入方法二）都沒用。直到（填入轉折事件），我才開始（填入新做法）。現在（填入你目前的結果）。如果你也卡在（填入讀者的痛點），（填入行動指令）」

---

### 2. 自我介紹

建立信任與使命感的結構，適合新粉絲第一次認識你的時候用。

**適用情境：** 個人頁釘選 Reel、About 頁面影片、新粉絲導流內容。

**逐段拆法：**
1. 「嗨我是（名字），X 年前我只是一個普通的（身分）」
2. 那時候的日常和限制
3. 發生了什麼讓一切不一樣
4. 現在在做的事
5. 收在「我在幫（客群）做（結果）」的使命宣言

**範例骨架：**
「嗨我是（你的名字），（填入時間點）年前我只是一個普通的（填入原本身分），每天（填入當時的日常限制）。直到（填入轉捩點），我才開始（填入現在做的事）。現在我在幫（填入客群）做到（填入結果）」

---

### 3. 課題

用一個震撼結果當鉤子，講失敗到成功的過程，最後留下一句能被截圖的體悟。

**適用情境：** 翻轉故事型內容，或需要先鋪陳方法論、再帶出系統的內容。

**逐段拆法：**
1. 鉤子：「這件事讓我（震撼結果）」
2. 一開始怎麼做都不對
3. 轉機出現的那一刻
4. 現在的做法
5. 體悟：一句能被截圖的金句

**範例骨架：**
「（填入震撼事件）讓我（填入結果）。一開始我（填入錯誤做法），完全沒用。直到（填入轉機），我才發現（填入洞察）。現在我的做法是（填入具體做法），體悟只有一句：（填入金句）」

---

### 4. 大目標／大夢想

記錄野心的起點、認真追求的過程、現在的進度，帶動追蹤與互動。

**適用情境：** 階段性戰報、進度更新、社群互動型內容。

**逐段拆法：**
1. 夢想是怎麼開始的
2. 認真追的那段時間做了什麼
3. 現在進度到哪
4. 收在互動型行動指令（留言、追蹤、加入）

**範例骨架：**
「（填入夢想起點）的時候，我（填入起心動念）。這段時間我做了（填入具體行動）。現在進度到（填入現況）。如果你也想（填入讀者渴望），留言（填入互動關鍵字）」

---

### 5. 從挑戰到勝利

把限制性信念翻轉成勝利，中間放系統，最後破除迷思。

**適用情境：** 化解反對意見的內容，或是「多數人以為要 X，做法是 Y」這類翻轉角度的腳本。

**逐段拆法：**
1. 一開始相信的限制性信念
2. 卡住的那段掙扎
3. 轉捩點
4. 解決方案／系統
5. 破除迷思的收尾

**範例骨架：**
「以前我也相信（填入限制性信念），所以卡在（填入困境）很久。直到（填入轉捩點），我才用（填入系統或方法）走出來。多數人以為要（填入常見迷思），做法是（填入你的做法）」

避免寫成「不是 X，是 Y」的句型，換一種說法會更自然，例如「A 的做法是 X，B 的做法是 Y」。

---

### 6. 突破

先講問題，再丟一個讓人意外的結果，最後解析怎麼做到的。

**適用情境：** 方法論教學型 Reels，開場數字或反差最強的時候特別有效。

**逐段拆法：**
1. 問題陳述
2. 意外的結果或洞察
3. 解析怎麼做到的（步驟化）

**範例骨架：**
「（填入問題陳述）」→「結果（填入意外結果）」→「背後的做法分三步：（填入步驟一）、（填入步驟二）、（填入步驟三）」

---

## 二、教學型結構（五種）

### 1. 三個層次

圍繞一個核心概念，分三層難度或深度來講。

**適用情境：** 教學型內容，適合做成輪播或多段 Reel。

**逐段拆法：**
1. Level 1：最基礎的做法
2. Level 2：進階做法
3. Level 3：高手做法

**範例骨架：**
「講到（填入主題），大部分人卡在 Level 1：（填入基礎做法）。進階一點是 Level 2：（填入進階做法）。真正的高手在做 Level 3：（填入高手做法）」

---

### 2. 兩種人

對比兩種做法，一種看起來對但沒用，一種反直覺但有效。

**適用情境：** 破除迷思型內容，或需要用反直覺角度當開場鉤的時候。

**逐段拆法：**
1. 第一種人：做法看起來合理，結果卻不好
2. 第二種人：做法反直覺，結果卻很好
3. 解析關鍵差異在哪

**範例骨架：**
「第一種人（填入常見做法），看起來很合理，結果（填入不好的結果）。第二種人（填入反直覺做法），聽起來很怪，結果卻（填入好的結果）。關鍵差異只有一個：（填入核心洞察）」

---

### 3. X vs X／最好與最差

兩個選項的對照分析，講清楚不同做法帶來的不同結果。

**適用情境：** 工具比較、策略比較、方案比較類內容。

**逐段拆法：**
1. 選項 A 的做法與結果
2. 選項 B 的做法與結果
3. 一句話總結該選哪個、為什麼

**範例骨架：**
「選項 A 是（填入做法一），結果是（填入結果一）。選項 B 是（填入做法二），結果是（填入結果二）。一句話：如果你（填入條件），選（填入建議）」

---

### 4. 行動→結果

最直接的因果句型列表，節奏快、資訊密度高。

**適用情境：** 編號語錄風口播 Reel、快節奏清單型內容，追求完播率的時候。

**逐段拆法：**
「如果你（做這個動作），你會（得到這個結果）」，重複三到五組。

**範例骨架：**
「如果你（填入動作一），你會（填入結果一）
如果你（填入動作二），你會（填入結果二）
如果你（填入動作三），你會（填入結果三）」

---

### 5. 你知道嗎

一步一步鋪陳資訊，最後導向一個具體結論。

**適用情境：** 知識型開場、數據型鉤子。

**逐段拆法：**
1. 「你知道嗎」型鉤子
2. 逐步鋪陳資訊或數據
3. 收在具體結論或行動

**範例骨架：**
「你知道嗎，（填入一個數據或冷知識）。這代表（填入鋪陳一），更進一步看，（填入鋪陳二）。所以結論是：（填入行動或結論）」

## 三、怎麼選：內容目標對照表

| 內容目標 | 建議結構 |
|---|---|
| 新粉絲第一次認識你 | 自我介紹 |
| 講一個翻轉故事 | 課題／突破 |
| 破除限制性信念 | 從挑戰到勝利／兩種人 |
| 教一個系統或方法 | 三個層次／突破 |
| 快節奏清單型、衝完播率 | 行動→結果／你知道嗎 |
| 階段性進度、生活戰報、社群互動 | 大目標／大夢想 |
| 比較工具或做法 | X vs X |
| 長版開場故事鉤 | 英雄旅程 |

## 四、套用備忘

- 所有結構都可以套用同一個公式：個人故事→系統洞見→行動指令
- 開場鉤子一律用短句起手，開場鉤子避免用破折號，也避免「你需要」「你應該」這類說教句型
- 「兩種人」「從挑戰到勝利」這類對比型結構，避免寫成「不是 X，是 Y」的句型，換一種說法會更自然，例如「A 的做法是 X，B 的做法是 Y」
- 範例骨架裡的括號都是佔位符，填入你自己的故事、數字、金句，結構本身可以重複用在任何主題上
