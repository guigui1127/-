# 限動導流系統

IG 限動是每天的轉換引擎：貼文負責被看到，限動負責把熱的人送進 DM 和名單。這套是 14 天序列制，每天一組 3 到 7 幀，全部收束到同一個 freebie 或 DM 關鍵字。

## 鐵律

- 照片先行，文字是配角：畫面承載時刻，字卡只放幾個字
- 每天一組一次發完，讓它自然過期，不要整天滴滴答答發
- 每組必有一個互動元件（投票／提問箱／滑桿／DM 回覆貼紙），沒有例外
- 每天只有一個 CTA，導向 freebie 或 DM 關鍵字，永遠不硬賣、不講價格、不喊「申請」
- 展示不敘述：提到 freebie 的幀要把它秀在畫面上（截圖、內頁、片段），讓人先嚐到價值再 DM
- 語氣像傳訊息給朋友，不像品牌廣播

## 四型限動

| 型 | 工作 | 關鍵規則 |
|---|---|---|
| 幕後型（跟我來） | 讓人想要你擁有的東西 | 從高潮開場不鋪陳；第一幀就放 DM 貼紙「回覆＿看我怎麼做的」；至少 3 幀（起、事、收）；不過度解釋，留缺口才有人回；結尾預告明天＋再放一次 DM 貼紙；必須連得到 freebie，連不到就只是日記 |
| 對話型（投票提問） | 讓人習慣跟你互動 | 投票兩選項，其中一個是「對的」但不明顯；提問箱收受眾卡點；只回答跟主題相關的問題；每個回答幀照樣放貼紙；提問序列收在 freebie |
| 成果型（讓人想要） | 「他做得到我也做得到」 | 指名道姓或具體描述（「台中的美髮師」可以，「我們一位客戶」不行）；每幀都有具體數字、before 狀態、產生變化的機制；順序：成果 → 背景 → 機制 → 轉變 → freebie CTA |
| 邀請型（freebie 日） | 把人送進 DM 或連結 | 第一幀把 freebie 秀在畫面上＋承諾一句＋DM 貼紙；一幀點名「這是給誰的」；一幀社會證明（多少人領了）；收在 DM 字或連結＋貼紙；不提價格不推付費 offer |

## 14 天序列地圖

### 第一週：建立渴望

| 天 | 型 | 主題 |
|---|---|---|
| 1 | 對話 | 爭議立場開週：極化一句話＋投票，收在「投完票明天告訴你我怎麼想」 |
| 2 | 幕後 | 從高潮開場：最近兩週的真實建置或勝利 |
| 3 | 對話 | 回答 Day 1 投票或提問箱最熱門問題，收在 freebie |
| 4 | 幕後 | 誠實日：有點不敢分享的失誤或掙扎（不覺得脆弱就選錯了） |
| 5 | 成果 | 一個具體有名字的成果：成果 → 背景 → 機制 → 轉變 |
| 6 | 邀請 | freebie 日：秀出來、給誰的、社會證明、DM 字 |
| 7 | 對話 | 人味收尾：低壓觀察＋提問箱，預告週一投票 |

### 第二週：加深信任、推向 freebie

| 天 | 型 | 主題 |
|---|---|---|
| 8 | 對話 | 更大膽的立場（信任變高了，重話才落地） |
| 9 | 幕後 | 兩週內最得意的建置或成果 |
| 10 | 對話 | 把最大反對意見包裝成一個真誠提問，完整回答，收在 freebie |
| 11 | 幕後 | 全週期最誠實的一天：出過的包＋學到的事 |
| 12 | 成果 | 更細的轉變：名字、起點、關鍵那一步、數字＋時程、他會對猶豫的人說什麼 |
| 13 | 邀請 | freebie＋誠實急迫感（只用真的存在的稀缺） |
| 14 | 對話 | 直接 DM 日：「看了兩週還不確定的人，DM 我＿＿，我把那個能立刻給你答案的東西傳給你」 |

## 貼紙配對邏輯

- 投票貼紙：兩選項，開週或立場日用
- 提問箱：收集卡點、回答熱門問題用
- 滑桿：低壓反應，回答幀和人味日用
- DM 回覆貼紙：主力武器，幕後日和邀請日的開頭與結尾都放
- 連結貼紙：省著用，DM 字通常轉換更熱

## CTA 輪換句庫（同一週不重複）

- 「回覆＿＿我傳給你」
- 「DM 我＿＿拿（freebie 名）」
- 「這份免費的＿＿就在講這個，DM 我＿＿」
- 「主頁連結免費領＿＿」
- 「免費拿，DM＿＿，不用填表單」

## 轉發測試

14 天裡至少一則要讓人想截圖傳給朋友：一句尖銳立場、一個意外數字、一個有名字的框架、或一個近到摸得到的成果。兩週內沒有一則過這個測試，就是立場太安全，重寫。

## 排程注意

- 若你有連接排程工具（如 Blotato 或 Metricool），可以用它排限動：一幀一則，一天一組排在同一時段連發
- 沒有連接排程工具就手動發，一樣是一天一組一次發完，不要滴滴答答
- 限動素材是照片或短片，文字產出時每幀都要附「照片指示」欄，你照著拍或選圖
- 每天限動的 CTA 要跟當天貼文的 CTA 同一個終點，限動是貼文的轉換層不是獨立系統

## 產出格式

```
### Day N（型｜主題）
目標：一句話

幀 1
照片：具體指示
字卡：（照發出來的樣子寫）
貼紙：投票／提問箱／滑桿／DM 回覆，含實際文字

幀 2
...（最後一幀帶 CTA＋貼紙）
```
