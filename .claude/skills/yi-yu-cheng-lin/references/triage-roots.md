# 分流與開枝

這是一語成林分流系統的核心工作：把逐字稿變成素材地圖與開枝計畫。逐字稿是根，素材地圖標出每一條根，開枝計畫決定每條根往哪些平台長出枝葉。

## 鐵則

逐字稿是本尊，AI 的詮釋不是。他講得好的句子直接標記原文位置，日後抬原話進成品。分流官的工作是找、標、排，不做重寫。

## 第一步：切段

整份逐字稿先讀完一遍抓整體形狀，再切段。一段＝一個完整的想法、故事或觀點。

## 第二步：六型標籤（每段第一層）

| 標籤 | 判準 | 最適合長成 |
|---|---|---|
| 故事 | 具體的時刻、地點、人物、結果 | 長文貼文、輪播、email 開場 |
| 系統 | 可重複的流程、規則、SOP | YouTube 大綱、教學 Reels、長脆 |
| 清單 | 三個以上的並列項目 | 輪播、編號貼文、清單信 |
| 反直覺 | 他相信但市場多數人不信的立場 | Threads 開頭、立場文、釘選貼文 |
| 金句 | 單獨成立、一句戳心的話 | 短脆、字卡、email 開場鉤 |
| 脆弱 | 失敗、恐懼、做錯的事 | 建立信任最快的長文與口播 |

一段可以有第二標籤，但只在真的兩者都符合時才給。

## 第三步：五類素材清單（每段第二層）

- 核心主張（他真正相信什麼、反對什麼）
- 痛點清單（這個主題解決受眾哪些問題，至少列 4 個）
- 故事（親身經歷、轉折、失敗、客戶案例）
- 方法（步驟、SOP、工具、示範）
- 證明（數字、成果、見證、可以 demo 的東西）

## 第四步：開枝對應（每段往哪些平台長）

先照「我的品牌根系.md」裡設定的 2 個主力平台餵飽，再往外擴。

| 標籤 | 開枝去向 |
|---|---|
| 故事 | 1 篇 Skool 或 IG 長文、1 組輪播（一幕一頁）、1 段 email 開場 |
| 系統 | 1 支 YouTube 大綱、1 則長脆（6 到 10 行）、1 組教學輪播 |
| 清單 | 1 組輪播、1 篇編號貼文、1 封清單信 |
| 反直覺 | 1 篇立場文、1 則短脆（可釘選）、1 組 3 幀限動 |
| 金句 | 1 則短脆、1 張字卡 Reel、1 個 email 開場鉤 |
| 脆弱 | 1 篇高信任長文、1 支口播 Reel 腳本 |

一份 60 分鐘的逐字稿正常能標出 15 到 30 段可用素材，長出 30 到 60 篇下游內容。

## 輸出格式

```
## 素材地圖
P1 [故事｜證明] 一句話摘要（逐字稿第＿段，金句原話：「＿＿」）
P2 [系統] 一句話摘要
...

## 痛點清單（至少 4 個，供 3×3×3 矩陣挑 3 個）
1. ...

## 開枝計畫
P1 → Skool 長文 ×1、輪播 ×1、email 開場 ×1
P2 → YouTube 大綱 ×1、長脆 ×1
...

## 直接可用的原話（抬進成品用）
- 「＿＿」（適合當 hook）
- 「＿＿」（適合當金句收尾）
```
