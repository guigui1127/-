# 影片生產線

每個影片座標走兩條路之一，由使用者在裂變地圖確認時勾選。預設 A 路（真人出鏡信任度最高），B 路給沒空錄或字卡型內容。

## A 路：自己錄（產「可直接錄」腳本卡）

每支影片交付一張腳本卡，格式：

```
## 腳本卡 #編號（平台｜模板｜預估秒數）

【Hook（唸出來的第一句）】
...

【正文（一行一句，照唸即可）】
...

【收尾（金句或行動指令）】
...

【拍攝備註】
- 場景建議：
- B-roll 清單（要補拍什麼畫面）：
- 字卡要打的字（如果有）：

【Caption（發文用，含 CTA）】
...
```

規則：

- 一行一句，每句能一口氣唸完，寫給嘴巴不是寫給眼睛
- 20 到 45 秒的口播稿控制在 90 到 160 字
- 錄完的粗剪交給你自己的剪輯流程（字幕、卡點、B-roll 動畫）

## B 路：影片生成工具生成（字卡動畫／虛擬人／UGC）

有連接影片生成工具（如 Higgsfield）的 MCP 時：

1. 先跑 `get_workflow_instructions`（不帶參數）看工作流目錄，再載入符合的：UGC 口播、講解影片、虛擬人口播等
2. 有聲音克隆需求時用 `create_voice`（首次）或 `list_voices` 取既有聲音
3. 影像素材：使用者照片用 `media_upload_widget` 收，網路素材用 `media_import_url`
4. 批次生成用 `generate_video_batch`＋`jobs_wait`，單支用 `generate_video`
5. 生成前必須把腳本、視覺方向、預估 credits 消耗列給使用者確認，確認後才生成（credits 是錢）

適合 B 路的內容型：D 類字卡 Reel、C5 編號語錄（配動畫字卡）、faceless 教學

## 分流判準

| 內容 | 建議路線 |
|---|---|
| 脆弱故事、身分反差 demo、權威證明 | A 路（真人不可取代） |
| 金句字卡、清單字卡、編號語錄 | B 路 |
| 精華 Reels（母內容切段） | 都不用，剪輯流程直接切 |

## 產出狀態標記

每支影片在日曆上標狀態：待錄製（A 路）／待生成（B 路）／待剪輯／可直接發
