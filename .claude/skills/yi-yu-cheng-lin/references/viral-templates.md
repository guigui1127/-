# 病毒模板庫

一語成林收錄 50+ 種已驗證的繁中平台格式骨架，裂變設計師產稿時查表使用。爆文之所以爆，八成是結構，兩成才是內容，所以我們維護一座「已驗證結構」的倉庫，判斷手上的素材標籤，自動挑最合的骨架填進去。

## 使用規則（產稿必讀）

1. 先看素材的六型標籤（故事／系統／清單／反直覺／金句／脆弱），每個模板都標了「吃什麼料」，只在料對的時候套
2. 骨架照抄，血肉必須是使用者的原話：逐字稿裡講得好的句子直接抬進去，不改寫成 AI 腔
3. 每篇填完三件事必須齊：hook（可從鉤子庫配）、內容、CTA 收束到「我的品牌根系.md」的唯一終點
4. 同一批產出裡，同一個模板最多用兩次，避免整排長一樣
5. 模板名稱不對外，成品裡永遠不出現「模板」「格式」這些字

## 骨架複製引擎（收到任何爆文範例時）

使用者丟來一篇別人的爆文說「照這個寫」時，跑這四步：

1. 抽骨架：逐行標出每一行的功能（鉤子行／立場行／證據行／轉折行／清單行／收束行／CTA 行）
2. 抽節奏：行長、斷行位置、清單數量、有沒有重複句式
3. 換血肉：把使用者的素材對應填入每個功能位，主題完全換掉，結構與節奏保留
4. 消毒：檢查沒有殘留原文的用詞、名字、行業梗，寫出來要像原生的，不像套的

抽完的骨架如果好用，問使用者要不要存進這份模板庫（加在對應平台區塊底下），庫會越用越厚。

## Hook 配對規則

- 每個座標的 hook 先查 `references/hook-library.md`（七大類：教學／對比／打臉迷思／故事／隨機／權威／日常實錄）
- 模板決定骨架，鉤子庫決定第一句，兩邊都要用
- 腳本層級的結構（英雄旅程、課題等 11 種）查 `references/script-structures.md`，適用於 C 類與 H 類的整支腳本
