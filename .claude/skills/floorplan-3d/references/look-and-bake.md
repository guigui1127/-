# 真实感画面和烘焙光照

## 网址参数（`look=pro` 才启用，不带时默认的分析图画面一点不变）

| 参数 | 作用 |
|---|---|
| `look=pro` | 透视相机、太阳 + 软阴影、柔光箱天光、后期（N8AO、泛光、移轴 / 景深、暗角、SMAA、Neutral 色调映射） |
| `pbr` | Poly Haven 的 PBR 贴图（木地板、石膏墙、亚麻、地砖）+ CC0 模型 + Blender 建的家具；同时启用软装（`nodecor` 关） |
| `mood=m1 / m2a / m2b / m2c / m3 / m4` | 午后暖阳 / 奶油阴天三个配色（胡桃木 + 炭灰、鼠尾草绿、陶土橙）/ 蓝调开灯 / 书桌上的微缩模型 |
| `tod=0..1` | 一天里的时间：0 正午 → 0.55 金色时刻 → 0.8 蓝调 → 1 夜里 |
| `view=eye` | 人眼高度 1.6 米，满层高 + 天花板；`cam=x,y,z&tgt=x,y,z` 换机位 |
| `view=eye&baked` | 人眼高度 + 烘焙的光照（蓝调开灯，m3 配色）；`bakeset=` 换烘焙文件夹（默认 `<户型>-m5`），`bexp=` 屋里曝光，`lmk=` 光照贴图亮度 |
| `night=n1 / n2 / n3` | 窗外夜景：程序城市 / 外滩背景板 + 江面 / 两者混合（默认 n2；背景板没做过就退回 n1） |
| `look=pt` | 浏览器路径追踪出静帧（很慢，只用来做参考图） |
| 调参 | `exp=` 曝光、`env=` 天光、`suni=` 太阳强度、`sun=` 太阳仰角、`sunaz=` 方位、`tm=neutral\|agx\|aces`、`fov=` |

## 各模块管什么（`src/look/`）

| 文件 | 管什么 |
|---|---|
| `look.js` | 网址参数、一天的光照关键帧、氛围预设、相机按画面比例贴合 |
| `ProStage.jsx` / `ProPost.jsx` | 太阳、天光、阴影相机贴合模型 / 后期链 |
| `pbr.jsx` | PBR 材质、世界坐标 UV、Blender 家具（`HERO_MAT` 按材质名换成共享材质） |
| `decor.js` / `Decor.jsx` | 软装规则（只看户型数据）/ 渲染和一件件落下 |
| `lamps.jsx` | 灯具、夜里的暖光、灯带 |
| `doors.jsx` | 门的姿态：室内门开进各自的房间、贴着墙；入户门、推拉门的开门动画 |
| `inside.jsx` | 满层高的墙、天花板、窗外 |
| `night.jsx` | 夜景三个方案 |
| `bake.js` | 导出给 Blender、加载光照贴图、材质补丁、每个房间的探针和门口的交叉淡化 |
| `tour.js` | 漫游时间线、落地、第一人称路线和规划器 |

## 软装规则要点（`decor.js`）

- 房间类型：`room.type` 优先，否则按名字（阳台、卫、厨、卧、书房、客、餐、玄关……）。
- 家具按 `FURN` 的尺寸算占地框；门在墙两侧各留开启区，推拉门两侧各留 0.75 米通道；窗不占地。
- 落地的软装（落地灯、边几、休闲椅、绿植）放之前查：在房间内框里、不压家具、不压门的开启区、不压已放的软装。
- 地毯可以压在沙发前腿、床的下 2/3 下面，碰到别的家具就往回缩，缩到 0.8 米以下不放。
- 挂画、镜子、毛巾只挂在家具正后方 0.6 米内、没有门窗的墙段上，整幅画落在同一个房间里。
- `phase` 决定落下的顺序：地毯 → 床品抱枕 → 灯和小家具 → 桌面摆件 → 绿植 → 挂画 → 窗帘。

## 烘焙流程

1. `node tools/bake-export.mjs --plan <户型> --set <户型>-m5`：打开 `view=eye&bake=export`，把整套房子（满层高 + 天花板 + 家具 + 软装）按世界坐标导成 `out/bake/<set>/scene.glb` + `meta.json`（每个物体的名字、静态 / 动态、灯的位置、天空、探针位置）。
2. `blender -b --factory-startup -P tools/blender/bake.py -- --set <set> [--res 4096] [--samples 512] [--ref]`：
   导入 → 灯（灯泡位置挂暖色点光源，灯罩自发光、厨卫吸顶灯换面光源）→ 天空（压掉月亮、压暗地平线、调成深蓝，存 `sky.exr`）→ 窗洞挂天光入口 →
   删看不见的面 → 静态物体展第二套 UV（按种类给像素密度）→ 合并成一个物体 → 背面比例图 + 法线图 → 烘漫反射（直射 + 间接）→ 扩边 → OIDN → 亮点和小斑再修一遍 → 存 EXR、`lm.glb` → 每个房间渲一张探针。
   输出在 `public/bake/<set>/`，`bake-log.json` 记用时、像素密度。只重做最后的修图：`--refilter`（20–45 秒）。
   可调：`--warm` 灯色、`--power` 各类灯的功率、`--shade` 灯罩自发光、`--led` 灯带、`--sky` 天空亮度、`--api CUDA|OPTIX`。
3. 页面（`bake.js`）按名字找到对应网格，换成带第二套 UV 的几何体，材质打补丁：漫反射 = 反照率 × 光照贴图，高光照旧（点光源 + 探针），PBR 质感还在。

- 静态（烘光照贴图）：墙、地板、楼板、天花板、栏板、家具、地毯、窗帘、抱枕、床品、边几、休闲椅、阳台桌椅。
- 动态（只当遮挡物）：灯具、绿植、花瓶、书、摆件、挂画、门窗；玻璃不参与。
- 网格的名字来自组件挂的 `userData.bake`（`wall:N:0`、`furn:3`、`decor:12`……）+ 组里第几个网格，导出和加载按同一规则数——**改了软装清单的顺序或家具的网格结构就要重新导出、重烘**。新加的软装接在清单最后面（`DECOR_EXTRA` 就是这样），前面的序号不乱。

## 参考数字（GTX 1050 Ti，CUDA）

| 设置 | 用时 |
|---|---|
| 2048²、384 采样（显卡同时被占着） | 光照贴图 6 分钟，整套 15 分钟 |
| 4096²、512 采样 | 光照贴图 23 分钟、扩边 3 分钟、OIDN 1.6 分钟、6 张探针 4.3 分钟，整套 32 分钟 |
| 4096²、512 采样，带温度看守暂停 | 整套 49 分钟 |

像素密度（像素/米）：地板 93、墙 79、家具 112、床品 126、窗帘 158、天花板 47。人眼高度实时 33–42 fps（1920×1080）。
