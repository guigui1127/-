# 漫游路线（`src/look/tour.js`）

`tour.js` 是纯函数，不依赖 three 和页面，node 里也能 import（`tools/tour-path.mjs` 用它量速度、查离墙多近）。

## 成片时间线（opus55，79.9 秒）

| 秒 | 画面 |
|---|---|
| 0–1.5 | 书桌上的图纸，斜上方推近 |
| 1.5–5.6 | 墙 → 门窗 → 家具 |
| 5.4–8.0 | 软装按房间成组落下 |
| 6–12.2 | 绕着转 + 一天过去 + 往入户门那边降 |
| 12.2–14.2 | 从入户门里的上空像升降臂一样直着降下来，边降边往客厅中间挪（`DESCENT`），2.8 米以下天花板才出现 |
| 14.2– | 第一人称（`ROUTE`）：厨房 7.5 → 绕餐桌 8 → 卫生间 6 → 次卧 10.4 → 主卧 11.2 → 穿过客厅 → 阳台 4.5（秒） |

下降段按从绕圈的末速度到走路的初速度做三次 Hermite：不打钩、落地不急停。

## ROUTE 的节点

| 字段 | 意思 |
|---|---|
| `p` | `[x, z]`（米；x 东、z 南） |
| `v` | 经过这一点的目标速度（米/秒），两点之间按路程插值；实际速度还受加速度、转头限制 |
| `hold` | 在这一点至少停多少秒（`v` 必须是 0）；停下的点把路线切成几段 |
| `yaw` | 朝向锚点（度；0 = 南，90 = 东，180 = 北，270 = 西）。**按字面值、不取近路**：212 → 25 是往右转 187°，182 → 364 是往左转 182°。锚点之间按时间线性插值（匀速转），最后整条高斯平滑。`"path"` = 跟着路线走向（可加 `lead` 度），过道拐弯用 |
| `yv` | 竖版的朝向锚点（不给 = 同横版），时间和横版共用 |
| `yawOut` / `yvOut` | 停下的点：离开时的朝向锚点。比出门方向差 20–40°，边走边转完，不在原地转到正对门口才走 |
| `sweep` | 从这一点到下一个朝向锚点按这个角速度（°/秒）匀速扫，停多久自动算 |
| `linger` | `[{ yaw, w, t }]`：扫到 `yaw ± w/2` 时放慢，多花 `t` 秒；还是同一个方向一直转 |
| `pre` / `post` | 停下的点：扫提前 `pre` 秒开始、推后 `post` 秒结束，扫的总时长不变，停的时间少一点 |
| `pitch` | 俯仰锚点（度，负 = 往下看），默认 −6 |
| `dip` | `{ yaw, depth, width }`：扫到 `yaw` 附近时低一下头（余弦形），看马桶用 |
| `slide` | 推拉门门口（`"K"` 厨房 / `"B"` 阳台），离它还有 `open` 米时开始滑开，`dur` 秒推开 |
| `beat` | 这一拍在干什么（分镜表用） |

## 规划器（`plan()`）怎么算

1. 路线按停下的点切段，每段过节点做向心 Catmull-Rom，按弧长 1 厘米重采样。
2. 每 1 厘米一个速度上限：节点速度插值；拐弯按横向加速度 `A_LAT` 1.1 米/秒² 限速；正反两遍按 `ACC` 0.75 米/秒² 限速，积分成时间，再在时间上高斯平滑。
3. 停留时长：`hold` 的最小值；朝向数组 → 至少 总角度 ÷ `YAW_CAP`；`sweep` → 按它的角速度扫完。
4. 朝向锚点按时间排开；两个锚点之间超过 `YAW_CAP` 35°/秒（俯仰 `PITCH_CAP` 7°/秒）的段放慢走路。
5. 120 Hz 采样成轨迹，录制时按时间查。

## 写一条新路线的顺序

1. 先定动线：入户门在哪、每个房间的门在哪、重点房间是哪几间、最后在哪收（阳台、窗边）。
2. 每个房间：门口外一点 → 门口（0.55 米/秒）→ 房间里停下的点（离大件白色家具 ≥ 1.2 米）→ 扫 → 出门。扫的方向选"最后正好转到门口"的那个方向。
3. 门往哪开、推拉门开哪半边：`DOOR_OVERRIDES[户型]`（门扇不进光照贴图，小改不用重烘）。扫到门口前经过的空墙：`DECOR_EXTRA[户型]` 补小画（接在软装清单最后，不打乱烘焙的序号）。
4. `node tools/tour-path.mjs && python tools/tour-path.py`（`--v` 竖版）：看最大速度、加速度、转头，离墙 / 门框 / 吊灯的最近距离，近处的墙占画面 > 25% 的时段。
5. `node tools/seq-stills.mjs --small --t 秒,秒 --name tour` 看关键时刻；再录 `--smooth` 预览 + `tools/judder.py`。

## 实测（第 8 轮定稿）

走路最快 1.04 米/秒、过门 0.55；转头最快 35°/秒（厨房、卫生间扫的那一下 37°/秒）；没有上下晃动。
躲不开的：进出卧室时门框占画面 55–65%，持续 1–1.5 秒（门洞太窄）。
