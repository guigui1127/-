# plan.json 格式

3D 生成器（`src/build/`）直接读这个格式。读图的结果按这里写，不要自己发明字段名。

## 坐标

- 单位：**米**
- 原点：图上**最左上那两根轴线的交点**（例如轴线 1 和轴线 A 的交点）
- x 向右（东）为正，z 向下（南）为正。图纸上方是北
- 墙的坐标一律用**墙中线**（一般就是轴线）

## 结构

```json
{
  "name": "一室一厅 · 约 45 ㎡",
  "height": 2.9,
  "walls": [
    { "id": "N", "a": [0, 0], "b": [7.2, 0], "t": 0.2 }
  ],
  "openings": [
    { "wall": "N", "at": 2.4, "w": 1.6, "type": "window", "sill": 0.9, "head": 2.1, "name": "卧室窗" }
  ],
  "rooms": [
    { "name": "卧室", "rect": [0, 0, 3.6, 4.2], "floor": "wood" }
  ],
  "rails": [
    { "a": [0, 7.5], "b": [3.6, 7.5] }
  ],
  "furniture": [
    { "type": "bed15", "at": [1.8, 2.6], "rot": 180 }
  ],
  "notes": ["读不准、靠估计的地方写在这里"]
}
```

### walls：墙
| 字段 | 说明 |
|---|---|
| `id` | 墙的名字，门窗靠它挂到墙上。随便起，唯一就行（`N`、`E`、`K1`…） |
| `a`, `b` | 墙中线的起点、终点 `[x, z]` |
| `t` | 墙厚（米）。外墙常见 0.24 / 0.2，内墙 0.12 / 0.1 |

一条直线上的墙，就算中间开了好几个门，也写成**一整段**；门洞用 openings 表示。

### openings：门窗洞口
| 字段 | 说明 |
|---|---|
| `wall` | 挂在哪面墙上（墙的 `id`） |
| `at` | 洞口**中心**到这面墙**起点 `a`** 的距离（米），沿墙方向量 |
| `w` | 洞口宽（米） |
| `type` | `door` 平开门、`slide` 推拉门、`window` 窗 |
| `sill`, `head` | 下沿、上沿离地高度。图上一般没有，用默认：门 0 / 2.1，推拉门 0 / 2.4，窗 0.9 / 2.1，卫生间高窗 1.4 / 2.1，飘窗 0.5 / 2.4 |
| `name` | 可选，例如"入户门" |

### rooms：房间
| 字段 | 说明 |
|---|---|
| `name` | 图上写的房间名 |
| `rect` | 房间范围 `[x0, z0, x1, z1]`，按墙中线。不是矩形的房间，拆成几个矩形各写一条，名字后面加编号 |
| `floor` | `wood` 木地板（卧室、客厅）或 `tile` 瓷砖（厨房、卫生间、阳台） |
| `outdoor` | 阳台、露台写 `true` |

### rails：阳台栏板（矮墙）
`a`、`b` 是栏板中线的起终点。

### furniture：家具（可选）
`type` 只能用下表里的类型；`at` 是家具中心 `[x, z]`；`rot` 是**正面朝向**：0 朝南（图纸下方）、90 朝东、180 朝北、270 朝西。

| type | 是什么 | 尺寸（宽 × 深，米） | 正面指 |
|---|---|---|---|
| `sofa` | 三人沙发 | 2.3 × 0.9 | 坐的人面朝的方向 |
| `coffee` | 茶几 | 1.1 × 0.6 | 长边方向 |
| `tv` | 电视柜 + 电视 | 1.9 × 0.4 | 屏幕朝向 |
| `dining` | 餐桌 + 4 把椅子 | 1.4 × 0.8 | 长边方向 |
| `bed18` / `bed15` | 1.8 米 / 1.5 米双人床 | 1.88 / 1.58 × 2.1 | 床尾方向（床头在背面） |
| `wardrobe` | 衣柜 | 2.4 × 0.6 | 柜门朝向 |
| `desk` | 书桌 + 椅子 | 1.2 × 0.6 | 坐的人面朝的反方向（椅子在正面） |
| `kitchen` | 一字橱柜 | 2.6 × 0.6 | 人站的一侧 |
| `fridge` | 冰箱 | 0.7 × 0.68 | 门朝向 |
| `shower` | 淋浴区 | 1.84 × 1.0 | 玻璃门一侧 |
| `toilet` | 马桶 | 0.4 × 0.65 | 坐的人面朝的方向 |
| `basin` | 洗手台 | 0.7 × 0.46 | 人站的一侧 |
| `plant` | 绿植 | 0.4 × 0.4 | 无所谓 |

图上画了家具轮廓就照着放；没画就不放，不要凭空加。

## 自检（写完 plan.json 必须过一遍）

1. 每个房间 `rect` 算出来的面积，和图上标的面积差不超过 0.3 ㎡
2. 外墙首尾相连，围成闭合的一圈
3. 每个洞口 `at ± w/2` 落在它那面墙的长度以内，同一面墙上的洞口互不重叠
4. 门窗总数和图上数到的一致（平开门、推拉门、窗分开数）
5. 读不准的地方写进 `notes`，不要假装确定
